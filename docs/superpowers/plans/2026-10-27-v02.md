# V0.2 Implementation Plan

> **For agentic workers:** usar superpowers:executing-plans na mesma sessão.

**Goal:** habilitar CEO e especialistas com fila durável e supervisão.
**Architecture:** API registra intenção; worker faz claim de uma etapa; LangGraph chama Codex; checkpoint transacional volta ao banco.
**Tech Stack:** FastAPI, SQLAlchemy, LangGraph, Codex CLI oficial, Next.js.
**Spec:** docs/superpowers/specs/2026-10-27-v02-design.md.

## Global Constraints
Sem shell de agente, repositórios externos, deploy ou credenciais no prompt. API não executa modelo. Cinco chamadas e 120s por etapa; custo monetário não estimado.

## Review Focus
Replay de aprovações; workers concorrentes; queda após inferência; cancelamento em voo; login indisponível; schema inválido; fallback de permissões proibido.
