# Pixel Office Map Implementation Plan

> Use superpowers:executing-plans inline; one independent read-only review.

**Goal:** Escritório top-down original com agentes circulando e estados reais.
**Architecture:** Componente SVG estático separado, sprites SVG e animação CSS;
PixelOffice mantém seleção, frescor e projeção existente, sem nova API.
**Tech Stack:** React/Next.js, TypeScript, SVG/CSS, Playwright/axe.
**Spec:** docs/superpowers/specs/2026-10-31-pixel-map-design.md

## Constraints / review
- Trabalho animado somente com lease/sinal backend; circulação é ambiental.
- Pause/reduced-motion/aba oculta/desconectado congelam personagens.
- Sem imagens externas, dependências novas, credenciais ou inferência paga.
- Teclado, alvos 44px, mapa rolável mobile sem overflow global, cores legíveis.
