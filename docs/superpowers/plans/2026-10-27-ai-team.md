# AI TEAM Implementation Plan

> **For agentic workers:** use superpowers:executing-plans para execução local por etapa.

**Goal:** entregar V0.1 funcional e avançar somente com dependências verificadas.
**Architecture:** monorepo; proxy Next.js -> FastAPI -> SQL; processo worker separado a partir de V0.2.
**Tech Stack:** Next.js 16, React 19, TypeScript, Python 3.12, FastAPI, SQLAlchemy, LangGraph.
**Spec:** `docs/superpowers/specs/2026-10-27-ai-team-design.md`.

## Global Constraints
- Não modificar outros projetos. Repositório GitHub privado `ai-team`.
- Sem deploy, pagamentos, exclusões ou segredos em logs.
- PT-BR, Windows + navegador, SQLite apenas local, PostgreSQL para hospedagem.

## Review Focus
- Senha incorreta, sessão vencida/revogada, brute force persistente: recusar.
- CSRF e origem ausente/estrangeira: recusar mutações.
- IDs inexistentes, entradas longas e transições inválidas: erros úteis sem gravação parcial.
- Persistência entre conexões e ausência de dados fictícios.
- Sem credenciais: integração indisponível e tarefas não executadas artificialmente.
