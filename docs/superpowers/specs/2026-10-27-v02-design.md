# V0.2 — orquestração persistente e Codex próprio

O login independente foi confirmado com `Logged in using ChatGPT`. O contexto usa keyring e diretório próprio fora do OneDrive. Esta versão entrega execução real de elaboração de planos e pareceres, sem ferramentas externas de desenvolvimento (V0.3) ou publicação (V0.4).

## Contrato
- Solicitação vinculada a um projeto e consentimento explícito para enviar seu conteúdo ao Codex.
- Grafo LangGraph: CEO planeja e delega -> DEV propõe implementação -> DESIGNER especifica UI -> QA revisa -> CEO consolida. Cada etapa é uma chamada limitada e produz artefato textual estruturado.
- Plano pode criar até seis tarefas locais, com origem auditada. Especialistas produzem propostas; nenhum status de tarefa é marcado como concluído automaticamente.
- Manual: aprovação antes de cada etapa após o planejamento inicial solicitado pelo usuário.
- Supervisionado: aprovação do plano antes do grupo de especialistas e consolidação.
- Automático: somente o escopo de elaboração textual autorizado na solicitação; não inclui ferramentas, repositórios, produção, exclusões, dados sensíveis ou pagamentos.
- Cancelamento persistente, decisões com etapa esperada e proteção contra duplo clique/replay.

## Durabilidade
Fila transacional no banco existente, sem Redis obrigatório no Windows. Claim por compare-and-swap e lease; uma etapa por claim. Saídas e consumo são checkpoints da aplicação em JSON SQL, com o índice da próxima etapa. O grafo executa a etapa selecionada e retorna ao worker para confirmar o checkpoint. Não usar InMemorySaver como persistência. Queda durante uma chamada deixa uma etapa incerta que é marcada como falha após a lease; não repetir automaticamente uma chamada possivelmente cobrada. PostgreSQL permanece sujeito a homologação própria.

## Limites e Codex
Máximo cinco chamadas por solicitação, timeout de 120s por chamada e teto acumulado de tokens para impedir a chamada seguinte. Não é um teto financeiro rígido: o CLI pode não fornecer preço monetário e só relata tokens ao terminar a chamada. Exibir custo indisponível quando não medido.

CLI oficial com stdin, JSON Schema e resultado estruturado. Processo sem shell, ambiente filtrado, keyring obrigatório, diretório temporário por chamada. Configuração estrita, permissões de filesystem limitadas ao diretório e runtime mínimo, rede de ferramentas bloqueada. Shell, execução unificada, plugins, apps, navegação Web e subagentes do CLI desabilitados. LangGraph coordena os papéis, não o multi-agent nativo do CLI. Nenhuma cópia de projetos ou credenciais no contexto do modelo. Não persistir raciocínio ou stdout bruto. Não fazer fallback para full access se o sandbox falhar.

## Validação
Testes locais com provedor injetado somente nas suítes: fluxo dos três modos, concorrência, aprovações obsoletas, cancelamento, falta de login, timeout, lease vencida e persistência de etapas. Homologação real separada, com solicitação sintética sem dados de projetos existentes, usando o Codex autenticado. E2E do formulário e das decisões; relatório distingue testes simulados da inferência real.
